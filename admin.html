⚙️ PENGATURAN KREDENSIAL SUPABASE

Dapatkan Project URL dan Anon Public Key gratis dari Dashboard Supabase Anda (supabase.com/dashboard → Project Settings → API).

Format: https://<project-id>.supabase.co
Kunci publik (anon key) aman digunakan di frontend GitHub Pages bersama Row Level Security (RLS).

📋 LANGKAH CEPAT KONEKSI KE SUPABASE (1 MENIT)

  1. Buka supabase.com, buat akun dan buat New Project baru.
  2. Buka menu SQL Editor di dashboard Supabase, lalu klik New Query.
  3. Copy seluruh isi file supabase_schema.sql (atau klik tombol copy di bawah) dan klik Run.
  4. Buka menu Project Settings → API, copy Project URL dan anon public key, lalu paste ke form di atas dan klik Simpan Config!
